## 🚀 Cosa sto costruendo

- **Piattaforma AI per PMI manifatturiere** — un "vibe coding platform" per la digitalizzazione di piccole e medie imprese manifatturiere, con focus sull'esecuzione locale di LLM per privacy e costi ridotti
- **Progetto MVNO AI-driven** — architettura per un operatore mobile virtuale (multi-IMSI/eSIM) per il mercato italiano
- **Assistente vocale locale in Python** — ispirato a J.A.R.V.I.S., con wake-word (Porcupine), speech-to-text (faster-whisper), TTS in italiano (edge-tts) e backend LLM
